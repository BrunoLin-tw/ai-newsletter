🧠 NVIDIA 對資料中心客戶下「51% 非中國營收」口頭令：租晶片的後門正在關 — 金融時報 11 月 3 日報導，NVIDIA 已要求全球資料中心合作夥伴縮減中國客戶業務：凡是轉租 NVIDIA 晶片的雲端業者，必須有至少 51% 的服務賣給非中國企業，否則可能失去硬體供應，且新規只適用未來合約、不追溯既有協議。這是把美國晶片繞道海外資料中心、再租給中國 AI 公司的路徑直接收窄——過去幾個月美國國會正是針對這條「境外算力後門」立法。NVIDIA 不承認也不否認，只發聲明說「建立在美國晶片上的資料中心與雲端，是美國模型與應用廠商在全球競爭的基礎」。中國外交部發言人毛寧稱未掌握該報導，並重申希望各國提供公平、透明、非歧視的營商環境。NVIDIA 目前是全球市值最高公司，這道不成文規矩等於把它自己的成長曲線與地緣政治綁得更緊。

🧠 墨芯人工智能完成近 10 億元 C+ 輪：稀疏計算推理晶片要拼下一代 SP200 — 深圳墨芯（Moffett AI）11 月 3 日宣布完成近 10 億元人民幣 C+ 輪融資，距離上一輪同樣近 10 億元的融資只有約五個月。資金將用於稀疏計算（sparse computing）推理晶片升級、下一代處理器研發，以及與研究機構和產業夥伴的合作。稀疏計算的核心是利用模型資料與運算中的稀疏性，把實際需要的計算量砍掉，換取更高吞吐與更低功耗——在推理成本成為 AI 商業化最大變數的 2026 年，這條路線的吸引力直線上升。墨芯稱已在中國四個區域部署推理叢集並與電信營運商合作，下一代 SP200 加速卡預計年底前到位。上一輪才五個月就再募一輪，說明中國本土推理算力的軍備競賽完全沒在減速。
🔗 [來源](https://technode.com/2026/11/03/ai-inference-chipmaker-moffett-ai-raises-nearly-rmb-1-billion-in-series-c-funding/)

🧠 Cogent VR-1.1 在 LiveCVEBench 拿下 57.9%：專用修漏洞模型第一次明顯甩開通用 coding agent — Cogent Security 11 月 3 日發布 VR-1.1，在 LiveCVEBench 的 190 個真實 CVE 修補任務中取得 57.9% 的通過率，Claude Code（Claude Opus 5.5）與 Codex（GPT-5.6-Cyber）各為 45.3%。測試條件相同、每題三次嘗試，只認最終能真正修掉漏洞的 patch。背景數字很刺眼：2026 年已公布超過 9 萬個 CVE，幾乎是 2025 年全年的兩倍；企業完整修補的中位時間從 32 天拉長到 43 天，而攻擊者平均比 patch 早一週開始利用。VR-1.1 的差別在流程——它會先自己建立漏洞脈絡、重現問題、寫修補、再驗證，而不是把修漏洞當成一般 coding 任務。專用模型在單一高價值任務上勝過通用前沿模型，這個模式在資安領域先站穩了。
🔗 [來源](https://www.cogent.com/blog/vr-1.1-on-livecvbench-remediating-real-vulnerabilities)

**🎮 有趣的小工具應用**

🎮 Snowflake Expedition 2026：Business Ontology 加 Cortex AI Gateway，把 agent 的「定義」與「權限」一次鎖死 — Snowflake 11 月 3 日在其年度大會宣布兩項核心能力。Business Ontology 進到 Horizon Context，讓企業把「淨營收」這類核心名詞的官方定義集中登錄、綁定底層表與檢視，並指定問責人；agent 只能拿到已核准的版本，第三方目錄或試算表裡的定義可以透過一次 CoCo 引導式工作階段搬進來，全部標成草稿等負責人核准，每次變更都留紀錄。Cortex AI Gateway 則是所有 agent 的單一前門：跨雲、跨框架、跨模型供應商套用同一組政策，agent 透過 MCP server 存取企業資料時，直接繼承人類使用者既有的權限與驗證。新加入的 Cortex Sandboxes 讓 agent 在資料旁邊跑自訂程式碼、自動套用執行者的權限、跑完就關；Agent Abuse Detection 則是看完整條 agent 軌跡（而不是單一 prompt）來抓越權與內部濫用。Snowflake 引用的調查說，55% 高階主管認為商業脈絡不足是 agent 產出品質低的主因。agent 上線真正的門檻，從來不是模型，是定義與權限。
🔗 [來源](https://www.snowflake.com/en/news/press-releases/expedition-2026-business-ontology-ai-gateway/)

🎮 Prime Intellect 開源 Prime Agent：把 context 當變數、把子 agent 當函式呼叫，harness 自己會改自己 — Prime Intellect 發布 Prime Agent，一個以兩個抽象為核心的開源 coding harness。第一個是 RLM（Recursive Language Model）：把 context 當成變數、把子 agent 委派當成 REPL 裡的函式呼叫，模型可以直接寫程式來平行 fan-out 子任務，子 agent 各自擁有模型、kernel、session tree 與對話歷史，回覆透過 agent_message 送回而不是回傳值。第二個是 Continual Harness：把 harness 自己的 prompt、子 agent 規格、skill、memory 變成可 CRUD 的狀態（rlm.harness.create_memory / create_skill / create_subagent），掛在常駐 IPython kernel 上，跨回合、跨 session 都留著；/refine 會讀 agent 自己的軌跡，只做最小幅度的編輯來改善下一次表現，並記錄觸發原因與結果。執行面有背景 daemon 管理所有 session，worker 掛掉可從 JSONL 與 kernel 快照還原，閒置 30 分鐘就從記憶體卸載、被叫到再載回。它的立場很明確：現在的 harness 是為舊世代模型設計的，固定的 tool schema 與 context 壓縮反而逼模型繞過自己的脚手架。
🔗 [來源](https://www.primeintellect.ai/blog/prime-agent)
