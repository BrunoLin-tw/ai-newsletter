**🔧 硬核技術更新**

🧠 Mistral 開源 Mistral Large 4：1 兆參數多模態模型，主打開源最強 coding 與防禦資安 — Mistral 把旗艦 Mistral Large 4（代號 Le Chonk）的權重放出來了。1.05 兆總參數的稀疏 MoE，每個 token 只激活約 49B（含 embedding 與輸出層 52B），原生多模態、1M 上下文，從頭到尾在歐洲基礎設施訓練。官方說法很硬：多三週 RL 之後，它在 FrontierCode 與 Terminal-Bench 上取得開源權重第一，Artificial Analysis Coding Agent Index 拿到 48，與 GPT-6.1 Terra 這類閉源模型同級，而且 token 效率明顯更好。三種 reasoning 模式可切換，權重採用自訂的 Mistral 開源權重授權（不是純 MIT），商業部署有條件。對想自架前線模型、又不想把資料送出去的組織，這是目前少數真的能下載的選項。
🔗 [來源](https://mistral.ai/news/mistral-large-4-oss/)

🧠 Factory Droid 1.0 把工具呼叫改成「寫程式」：Terminal-Bench 4 拿 65.2%，成本再降 15% — Factory 發布 Droid 1.0，最大的改動是把 programmatic tool calling 變成預設：模型不再把每次工具輸出塞回 context，而是寫一段 JavaScript 在沙箱裡跑（無檔案、無網路、無系統權限），只有程式印出來的東西會回到模型。效果很具體——修一個單元測試從 15 次工具呼叫、10 次模型呼叫降到 5 次，41.6 秒完成而非 56.8 秒；一個清理任務用 312 次工具呼叫、2 次請求、約 6.1 萬 tokens 搬完 151 個 issue，換成直接呼叫則要 36 次請求、310 萬 tokens。CI 掃描 5,384 個 job、547 次 run 只花 2 次請求，不到 0.1% 的工具結果進到 context。base prompt 縮小 37% 到 13,055 tokens、初始工具定義只剩兩個，Claude Opus 5.5 上 Terminal-Bench 4 達 65.2%，每個通過任務 $4.73，整體比直接呼叫便宜最多 24%。
🔗 [來源](https://www.artiverse.ca/factory-droid-10-turns-one-model-request-into-hundreds-of-tool-calls/)

**🏢 大廠最新動態**

💰 Meta 找上中國 Fourier 三個月做出人形機器人 Max，第二版已在開發 — The Information 報導，Meta 與上海 Fourier 合作，三個月內做出代號 Max 的人形機器人原型：約 1.5 公尺高、106 磅重，8 月做內部演示，9 月起著手第二版。Meta 回應稱這是「內部研究與實驗」，沒有販售計畫，但機器人副總 Li-Chen Miller 在 Fourier 上海廠待了將近兩個月，量產問題顯然沒被排除。時機很尷尬：FCC 九月已把外國生產的先進機器人放進國安 Covered List，新機型要拿設備授權，得在美國製造且本土零組件成本占比超過 65%（2028 年前）、2029 年升到 75%。也就是說，Meta 一邊靠中國供應鏈做快原型，一邊撞上美國自己築的牆。
🔗 [來源](https://thedeepdive.ca/meta-turns-to-china-to-build-humanoid-robots-as-trump-restricts-foreign-ones/)

💰 DeepMind 的 Gemini 都市計畫工具 PlanAssist 擴大到 15 個英國自治體 — Google DeepMind 與英國政府、Google Cloud、Faculty 合作的 PlanAssist，在 Barnet、Camden、Dorset 三地試辦後，再開放 12 個英格蘭自治體加入，總數達 15 個，進入為期 12 個月的 live beta，分三批上線。工具會讀申請文件與圖說、查樹木保護令這類文資限制、比對地方與國家政策及先前陳情意見，然後產出一份帶引用的報告讓承辦人修改——最終決定權仍在具資格的規劃官手上。試辦數據是特定任務的處理時間平均降 58%（官方說法為「最高 58%」），官方計畫若測試順利，2027 年推廣到全英格蘭，且不強制使用。這是 Gemini 在文件密集、法規密集的公共部門拿到的第一個規模化參考案例。
🔗 [來源](https://creatorstoolbox.com/blog/google-deepmind-planassist-uk-councils)

**🎮 有趣的小工具應用**

🎮 微軟與 Berkeley 開源 TokenEconomizer：不改 agent，coding 成本直接降 18–31% — 微軟研究院與 UC Berkeley 把 TokenEconomizer 開源（Apache 2.0，論文 arXiv 2610.22732）。它不改模型、不改 agent，只是接在旁邊學你已經跑過的 session：記住這個 repo 怎麼運作（該用什麼指令跑測試）、按任務把用不到的工具定義砍掉、偵測 agent 開始重複同一個錯誤時叫它換路。在 SWE-Bench 的 277 個任務、五組 agent–model 組合上，平均成本降 18.4% 到 30.9%，30 個 repo×組合格子全部變便宜，Pass@1 還有 4 組上升。支援 Claude Code、OpenAI Codex、GitHub Copilot CLI 與 Pi。對每天掛 agent 跑長任務的人來說，這比換模型實在。
🔗 [來源](https://github.com/microsoft/TokenEconomizer)
