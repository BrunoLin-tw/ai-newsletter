**🔧 硬核技術更新**

🧠 NVIDIA 把 Jetson Orin 的 DLA 推論帶進 Python — `cuda.bindings.cudla` 讓開發者不寫 C++，就能用同一條 CUDA stream 串起 GPU 前處理、DLA 推論與 GPU 後處理；模組隨 `cuda-bindings` 13.3.0 提供。
🔗 [來源](https://developer.nvidia.com/blog/run-native-dla-inference-in-python-on-nvidia-jetson-agx-orin-using-cudla/)

🧠 NVIDIA SOMA Retargeter v0.2 讓人類動作更快搬上人形機器人 — 開源工具透過共用骨架、逆向運動學與腳掌修正，把動作轉成機器人關節軌跡，已附 Unitree、Booster 與 AgiBot 五款機器人設定。
🔗 [來源](https://developer.nvidia.com/blog/adapt-human-motion-for-robots-with-nvidia-soma-retargeter/)

💰 Google Cloud 統一 BigQuery 與 Looker 的 AI agent 可觀測性 — 第一方與 ADK、LangGraph 第三方 agent 都能把遙測送進 BigQuery，追蹤推理、工具延遲、token 成本與品質，同時分離營運指標和對話內容。
🔗 [來源](https://cloud.google.com/blog/products/data-analytics/enterprise-ai-agent-observability-with-bigquery-and-looker/)
