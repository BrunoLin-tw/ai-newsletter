**🔧 硬核技術更新**

🧠 Google 的軌道 TPU 真的跑起来了：Gemma 4 在太空寫下第一首詩 — Project Suncatcher 的原型衛星 10 月 1 日發射後，花三週做完 commissioning，本週達到「Hello World」里程碑：地面站在衛星通過時 uplink 一個 prompt，衛星上的 Gemma 4 生成一首俳句，訊號在飛越挪威 Svalbard 時下載成功——「Blue marble below / Data streams in silent grace / Starlight feeds my core.」這是史上第一次由資料中心等級 TPU 在軌道產生 AI 回應。硬體現實很硬：衛星帶四顆 TPU、太陽能上限 1kW，一次只能開一顆、約 20 分鐘就得靠輻射散熱，接下來要測散熱與宇宙射線造成的 bit flip。若撐得住，2027 年要打兩顆互連衛星、加雷射鏈路。
🔗 [來源](https://blog.google/innovation-and-ai/models-and-research/google-research/project-suncatcher-satellite-response/)

🧠 NVIDIA 悄悄下修 Rubin 規格：HBM4 頻寬少 11%、NVLink scale-up 砍 17% — 隨著 Vera Rubin 進入量產、第一批 NVL72 開始交貨，NVIDIA 把先前掛「preliminary」的規格定案，結果是往下修：單顆 Rubin 的 HBM4 頻寬從 22TB/s 降到 19.2TB/s（每 pin 9.375Gbps，少約 11%），scale-up 的 NVLink 從 3.6TB/s 降到 3.0TB/s，只有 scale-out 網路從 0.4TB/s 升到 0.45TB/s。容量與算力不動：288GB HBM4、NVFP4 推論 50 PFLOPS、訓練 35 PFLOPS。作為對照，AMD MI455X 的 HBM4 只跑 7.6Gbps/pin，NVIDIA 降完仍高一截。官方沒解釋原因，外界普遍解讀是 HBM4 供應鏈交不出原本的時脈。
🔗 [來源](https://www.servethehome.com/nvidia-updates-rubin-gpu-specs-as-first-production-hardware-arrives/)

🧠 AMD 用推論成本反打：MI355X 跑 Kimi K3 2.8T，每 token 比 GB200 NVL72 便宜 46% — SemiAnalysis 的 InferenceX 把 2.8 兆參數的 Kimi K3 放上兩邊對比（FP4、8K in／1K out）：高互動場景 165 tok/s/user 時，MI355X 每百萬 token $0.15、GB200 NVL72 $0.22，差 46%；118 tok/s 時是 $0.14 對 $0.16（20%）；放寬到 71 tok/s 則是 $0.05 對 $0.07（35%）。關鍵輸入是晶片持有成本，GB200 NVL72 每 chip 每小時 $1.86、MI355X $1.50。代價在併發：165 tok/s 時 GB200 每顆晶片服務約 8 位使用者、MI355X 只剩 4 位，所以這個「便宜」是用一半的吞吐換來的。方法論仍是單一廠商模型，但對正在算 agent 推論帳的人，這是目前最具體的一組數字。
🔗 [來源](https://inferencex.semianalysis.com/compare-per-dollar/kimi-k3-gb200-vs-mi355x)

**🏢 大廠最新動態**

💰 Aramco 砸 26 億美元吃下 HUMAIN 49%：PIF 保留 51%，目標 2030 年 3GW AI 資料中心 — PIF 與 Aramco 11 月 1 日宣布交易完成：Aramco 透過全資子公司取得沙烏地 AI 國家隊 HUMAIN 的 49% 股權，對價是移轉關鍵 AI 資產加上 2026 年約 99 億里亞爾（26 億美元）現金，PIF 維持 51% 控股。兩邊都把 AI 資產、算力與人才倒進 HUMAIN，目標是 2030 年前部署 3GW 的 AI 資料中心容量。Aramco 執行長 Nasser 說 2023 年以來集團「Technology Realized Value」累計 113 億美元、其中很大一塊來自 AI 方案，這筆交易是要把 AI 從內部效率工具變成可變現資產。對照同週 OpenAI 募資目標砍到 200 億美元、估值退回 1.25 兆，主權基金那邊倒是越買越兇。
🔗 [來源](https://www.aramco.com/en/news-media/news/2026/pif-and-aramco-close-humain-transaction-to-accelerate-humains-global-growth)

💰 蘋果在中國把 Qwen 塞進 Apple Intelligence：11 月 4 日開發者 beta、12 月隨 iOS 27.3 上線 — 阿里巴巴與蘋果 10 月 31 日宣布合作，Qwen 將進駐中國版 Apple Intelligence，涵蓋 Siri、Writing Tools 與 Visual Intelligence 的文字與影像理解、內容生成。開發者 11 月 4 日就能在最新 iOS beta 試，正式版隨 12 月的 iOS 27.3 推送給中國用戶，適用於在中國購買支援 Apple Intelligence 的 iPhone，或裝置地區與 Apple Account 都設為中國的機型。重點在條款：使用者可自行決定是否啟用、要分享哪些資訊，阿里承諾不會把用戶請求和生成結果拿去訓練。這是首次有頂級全球消費硬體廠把中國大模型當成中國市場的系統級 AI 主幹。
🔗 [來源](https://news.cgtn.com/news/2026-10-31/Alibaba-s-Qwen-to-integrate-into-Apple-Intelligence-in-landmark-deal-1RHilSeJsbK/p.html)

**🎮 有趣的小工具應用**

🎮 DeepSeek 開源 Super-Agent：不是等你敲它，而是盯著群組聊天自己開 PR — DeepSeek 的 Harness 團隊 10 月 31 日在 GitHub 放出 dsh-superagent，MIT 授權，兩天衝破 7,000 星。架構是 Router-Worker：Router 常駐監看一個 GitHub repo 與（可選的）飛書群組，看到被授權的人交辦工作就開一張 ticket，丟進獨立 session 平行處理，重現問題、改、跑測試，最後回原討論串貼 PR；需要人決策的才列在 web 面板上。官方原則一句話：「Take as little human attention as possible, and give as much value as possible.」DeepSeek 自己強調這是研究原型、不是官方產品，公開版和內部版有落差，跑之前要自己審。此舉擺明對標 Claude Code。
🔗 [來源](https://thenextweb.com/news/deepseek-super-agent-open-source-coding-agent)

🎮 Vercel 開源 agent-desktop：不截圖猜像素，直接讀作業系統的無障礙樹 — Vercel Labs 的 agent-desktop 是 Rust 寫的 CLI 加 C 函式庫（Apache-2.0），macOS、Windows、Linux 通吃，讓 coding agent 透過 OS 的無障礙 API（macOS AX、Windows UI Automation、Linux AT-SPI）看到原生 App 的真實 UI 結構，回傳帶 ref 的 JSON，agent 對 ref 動作後再快照確認——不用影像比對，ref 穩定、動作可安全重試。多個 agent 可以各自帶一個螢幕游標 headless 平行操作，人照樣用同一台機器。Vercel 自己的測試把一個 52 步的 Apple Maps 任務從 19.8 萬 tokens 壓到 3.1 萬。`npm install -g agent-desktop` 就能裝，macOS 需開輔助使用權限。
🔗 [來源](https://github.com/vercel-labs/agent-desktop)
