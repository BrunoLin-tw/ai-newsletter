**🎮 有趣的小工具應用**

🎮 Exa 推出 Agent Ultra：把任務切給一整群 subagent 的「跑到窮盡」深度研究 API — 這是 Exa Agent 的最高強度模式，主打大型清單建構、實體資訊補全，以及需要數千個來源的問題。它把任務拆成子任務、派多個 subagent 同時研究不同領域，只在真正需要前沿智慧的步驟才路由到前沿模型。Exa 稱其在 WANDR、DeepSearchQA、WideSearch、Company Find-All 四項基準上，都勝過 Opus 5.5、GPT-6 Astra 與 Perplexity Agent 的最高強度設定；複雜任務約 30 分鐘完成，最難的可跑到 3 小時。API 以 `effort: "ultra"` 啟用，按標準 Agent 用量計費。
🔗 [來源](https://exa.ai/blog/exa-agent-ultra)
