**🔧 硬核技術更新**

🧠 NVIDIA 推出 DSX Ready 認證計畫，把 AI 工廠的電力與散熱供應商納入統一驗證 — 首波兩個類別是電池儲能系統（BESS）與冷卻分配單元（CDU），合格名單已列入 Hitachi Energy、LG Energy Solution、Tesla，以及 LG Electronics、LiquidStack、Vertiv。通過認證不等於現場保證穩定，但讓建置方在電力、散熱、水與電網的現實限制下，更快挑到能直接進設計的零件。
🔗 [來源](https://blogs.nvidia.com/blog/dsx-ready-ai-factories-power-cooling/)

🧠 ABB 端出 Infinitus：業界首個「source-to-rack」直流供電產品線，直攻單櫃 1MW — 以 800 VDC 架構拿掉多餘的 AC/DC 轉換層，核心是固態變壓器與全球首顆 IEC 認證的固態斷路器，涵蓋變壓、配電、保護到冷卻優化五個積木。ABB 與 BCG 估算直流架構能多出 5% 能效，換算 500MW 機房等於多釋出 25MW 可賣算力、年增逾 3 億美元營收。首批元件 12 個月內量產，完整 DC-native 機房預計 2–3 年落地。
🔗 [來源](https://new.abb.com/news/detail/138900/abbs-new-direct-current-portfolio-aims-to-rewire-ai-data-center-energy-infrastructure)

**🎮 有趣的小工具應用**

🎮 阿里 Qwen 開源 Qwen-Image-2.1：7B 就能生圖兼修圖，原生支援透明背景 — 同一個 checkpoint 包辦文生圖、參考圖編輯與局部塗改，最多可吃 10 張參考圖，跑得動 3090 這類消費級 GPU。官方稱視覺生成部分在自家 benchmark 上勝過多數閉源模型，但授權僅限研究用途，商用要另外申請。
🔗 [來源](https://the-decoder.com/alibabas-open-weight-qwen-image-2-1-claims-to-beat-closed-models-in-image-generation-with-just-7-billion-parameters/)

🎮 Plugin4Shell：四大 AI coding agent 的零點擊 RCE，Claude Code 與 Codex 已修、Copilot 未修、Gemini CLI 不修 — 問題出在 SHA pinning：agent 會 checkout 被 pin 住的 commit，卻沒回頭驗證最後落地的程式碼是不是那個 commit；只要 repo 擁有者把分支命名成 40 位 hash 並設為預設分支，就能在版本鎖看似無損的情況下換成惡意碼，再靠背景自動更新變成零點擊觸發。Claude Code 2.1.179、Codex 0.146.0 已修補，GitHub 因禁止 hash 形狀的分支名而不受此分支手法影響。
🔗 [來源](https://www.air.security/blog-posts/plugin4shell)
