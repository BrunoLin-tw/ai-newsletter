🧠 Cerebras 牽手 Gimlet Labs，部署 100MW CS-4 推論算力 — Cerebras 與雲端新創 Gimlet Labs 宣布合作，要以晶圓級 CS-4 系統打造專為推論而生的解構式（disaggregated）雲端，雙方計畫達到約 100MW 容量、最高每秒 3,000 token 的輸出速度，鎖定 agentic 與即時應用。Gimlet Cloud 把 Cerebras Wafer Scale Engine 與 GPU 混搭，依推論各階段（prefill、decode、attention）分配給最合適的矽；首座 Cerebras 驅動的 Gimlet 資料中心預計今年內上線，客戶可望 2027 年用到 CS-4。
🔗 [來源](https://www.cerebras.ai/press-release/gimlet-labs-adds-cerebras-to-deliver-ultrafast-ai-inference-through-gimlet-cloud-deployment)

🧠 SEMIFIVE 拿下 5,200 萬美元 AI 推論加速器 ASIC 大單 — 韓國客製化 ASIC 廠 SEMIFIVE 宣布與一家美國 AI fabless 公司簽下約 703 億韓元（約 5,200 萬美元）合約，為其開發資料中心等級的次世代 AI 推論加速器。這是 SEMIFIVE 史上最大單一合約，也是北美首個「Spec Hand-off」專案——客戶只給高階規格，設計、軟體、封裝、測試到量產全由 SEMIFIVE 包辦；晶片採 LPDDR6 記憶體與 PCIe Gen5，預計 2027 上半年在三星晶圓廠 tape-out、2028 年量產。
🔗 [來源](https://www.taiwannews.com.tw/news/6448173)

🧠 仁寶前進 OCP 高峰會，端出 NVIDIA AI 工廠整櫃方案 — 仁寶宣布將在 OCP Global Summit 2026（10/12–15，聖荷西）展出新一代 AI 工廠基礎設施，主打以 NVIDIA 加速運算為核心的整櫃級設計。面對單櫃突破 MW 等級的功耗與熱密度，仁寶把電力、散熱、運算與機櫃工程綁在一起解：導入 800VDC 高壓直流供電架構、直達晶片的直接液冷（DLC）與高效率 CDU，並以 NVIDIA MGX 等平台打造可部署的 AI 工廠藍圖。

**🎮 有趣的小工具應用**

🎮 NVIDIA 開源 TensorRT Model Connect：一個從第一天就為 coding agent 設計的專案 — NVIDIA 開源 TensorRT Model Connect，一組以 C++ 撰寫、建構在 TensorRT 之上的 AI 模型參考實作。專案起初是「用 coding agent 開發」的實驗，後來轉向更根本的問題：如果一個正式專案從第一天就為 AI agent 設計，會長什麼樣？答案不是複雜的 orchestration 或更多 prompt，而是把 AI 輸出視為可驗證的模組化工作單元、隔離各模型家族的變更讓失敗保持局部、讓改動易於評估與回退，並以自動化驗證當作交付的硬約束。
🔗 [來源](https://developer.nvidia.com/blog/ai-native-by-design-lessons-learned-from-building-nvidia-tensorrt-model-connect/)

🎮 Hivelocity 推 NVIDIA L4 裸機方案，主打本地小模型推論 — 主機商 Hivelocity 在裸機方案中加入 NVIDIA L4 Tensor Core GPU，鎖定 3B–13B 的小型語言模型（SLM）本地推論。L4 具備 24GB GDDR6、300GB/s 頻寬與 72W 低功耗，原生支援 FP8/INT8/INT4，單卡就能跑 Qwen、Llama、Mistral 等 7B–9B 模型；搭配 vLLM 或 Ollama 即可自架。裸機沒有虛擬化開銷、資料留在單租戶環境，且以月租取代按 token 計費，對隱私敏感或想壓成本的企業場景更有吸引力。
🔗 [來源](https://www.manilatimes.net/2026/09/30/tmt-newswire/globenewswire/hivelocity-brings-gpu-accelerated-local-ai-capabilities-to-its-bare-metal-bundles/2435541)
