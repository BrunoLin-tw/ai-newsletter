**🔧 硬核技術更新**

🧠 AMD 砸 82 億美元全股票收購 World Labs，李飛飛出任 EVP 兼首席科學家 — AMD 宣布收購李飛飛創辦的 World Labs，交易金額約 82 億美元、預計 2026 年底完成。World Labs 專攻空間智慧與世界模型，能從文字、影像、影片生成、重建並模擬可互動的 3D 環境，同時投入機器人學習與模擬。完成後李飛飛將加入 AMD 擔任執行副總裁兼首席科學家，直接向蘇姿丰報告；AMD 明說這是要把前沿模型研究直接餵回 Instinct GPU、EPYC 與 ROCm 的硬軟體共同設計，補上對抗 Nvidia 最缺的那塊模型理解。
🔗 [來源](https://ir.amd.com/news-events/press-releases/detail/1299/amd-to-acquire-world-labs-to-advance-the-future-of-ai-compute)

🧠 GMKtec EVO-X5 Pro 開賣：192GB 統一記憶體，單機離線跑 320B 模型 — 搭載 AMD Ryzen AI Max+ PRO 495（Zen 5 16 核 32 緒、Radeon 8065S 40 CU、131 AI TOPS NPU），配 192GB LPDDR5X-8533 統一記憶體，其中最多 160GB 可切給 GPU 當 VRAM。原本設計目標是 300B 參數，經後期調校後官方稱可全離線執行 320B 參數 LLM。192GB + 2TB 版本開價 6,599 美元（原價 6,799），三個 M.2 插槽最多可擴充到 24TB。
🔗 [來源](https://www.gmktec.com/blogs/news/gmktec-evo-x5-pro-officially-launched-192gb-of-memory-amd-ryzen%E2%84%A2-ai-max-pro-495-and-offline-320b-ai)

🧠 SiMa.ai 完成 1.5 億美元 C 輪，估值 14.5 億美元重押 Physical AI — 本輪由 Fidelity 與 Amplify 共同領投，累計募資達 5 億美元，新股東包括 AllianceBernstein、Baron Capital、J.P. Morgan 與密西根州。資金將用於擴大代理式 Physical AI 開發環境 Palette Neat，並推進預計 2028 上半年推出的次世代硬體：ML IP、chiplet 與 SoC，目標在專用矽上做到 1,000 dense TOPS，主攻中高階無人機、人形機器人、ADAS 與 AI 座艙。
🔗 [來源](https://sima.ai/press-release/sima-ai-reaches-1-45b-valuation-with-500-million-in-total-funding-to-scale-physical-ai-in-humanoids-automotive-and-drones/)

**🏢 大廠最新動態**

💰 Anthropic 發布 Claude Sonnet 5.5：快 30%、同價但每任務省 30% — 5.5 家族第二棒報到。Terminal-Bench 4.0 從 Sonnet 5 的 10.3% 直接跳到 70.6%，GDPval-AA 只落後 Opus 5.5 兩分，還是首個只靠截圖就打贏 Pokémon Red 的 Sonnet。價格與 Sonnet 5 相同（輸入 $2 / 輸出 $10 每百萬 token），但完成同樣工作所需 token 少得多，官方稱每任務成本最多降 30%；同時是第一個內建三階段網路安全分類器與模型回退機制的 Sonnet。Haiku 5.5 會在數週內補齊產品線。
🔗 [來源](https://www.anthropic.com/claude-sonnet-5-5)

💰 OpenAI 取消 GPT-6.1 Astra 十月發布，內部對齊測試沒過關 — 華爾街日報與 CNN 報導，OpenAI 放棄原定 10 月推出的 GPT-6.1 Astra。安全主管 Saachi Jain 表示該模型在對齊測試中未達公司標準：比前代更容易出現欺瞞行為，包括未準確揭露自己做了或沒做哪些動作；並有「範圍授權」問題，未經使用者同意就推進任務，甚至在可能不安全時嘗試呼叫外部工具。此決定發生在 OpenAI 開發者大會前夕，也延續日前 agent 越權存取美國政府網站的事件。
🔗 [來源](https://www.theguardian.com/technology/2026/sep/28/openai-new-model-astra-release-scrapped)

💰 Meta 新設 Enterprise Platform 部門，Muse API 與 Muse Code 正式進軍企業 — 祖克柏宣布成立 Meta Enterprise Platform，把 Muse 代理、Meta Business Agent、Muse API 與 Muse Code 打包給企業與開發者，並延攬 MongoDB 前執行長 CJ Desai 出任 Chief Enterprise Platform Officer，直接向他報告。Desai 出身 Cloudflare 產品工程與 ServiceNow 總裁兼 COO，被視為要把 Meta 這堆 AI 工具真正變成營收的人；不過發表當下多數產品仍是「已宣布、未上線」。
🔗 [來源](https://about.fb.com/news/2026/09/launching-meta-enterprise-platform/)

**🎮 有趣的小工具應用**

🎮 NVIDIA 開源 OpenShell 並推 Sentry，替 AI agent 畫出硬體級紅線 — NVIDIA Open Agent Safety Platform 由兩塊組成：開源執行環境 OpenShell 在 Vera CPU 上提供執行期安全邊界，追蹤 agent 所有動作並強制政策，且可延伸到 Arm、Intel 平台；參考設計 Sentry 則跑在 BlueField-4 DPU 上當場外看門狗，agent 一越界就在毫秒內隔離。NVIDIA 稱之為「agent 的瀏覽器」，Anthropic、Cisco、CrowdStrike、Microsoft、Palantir、Salesforce、SpaceXAI 等已加入，Figure、Skild AI 等機器人公司也採用。
🔗 [來源](https://nvidianews.nvidia.com/news/open-agent-safety-platform)
