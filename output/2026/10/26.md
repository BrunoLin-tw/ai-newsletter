**🔧 硬核技術更新**

🧠 IQuest-Q1 開源 320B/15B 稀疏 MoE：Terminal-Bench 2.1 衝 83.2，直接掛進 Claude Code 與 Codex CLI — 88 層、256 個 expert 每 token 只路由 8 個，總參數 320B 但每步只啟用 15B，配 512K context，主打「前沿輸出、小模型推論成本」。訓練拆三階段：穩定預訓練、把 context 漸進拉到 512K 的中期訓練、再混 SFT 與領域 RL 做多 scaffold 後訓練；論文聲稱比 baseline 多 1.93 倍 scaling 效率。原生支援 Claude Code 與 Codex CLI 掛鉤，SGLang 首日就跟上。要留意的是同份表格裡 Terminal-Bench 3.0 只有 17.9、4.0 是 22.7，別只看被放大那一個分數。
🔗 [來源](https://arxiv.org/abs/2610.30949)

🧠 十年前的 CNN 打贏前沿 LLM：皮膚癌切片判讀 62% 對 42% — Guy's Hospital 皮膚科醫師 Magnus Lynch 拿 ISIC MILK10k 裡 200 個組織病理確診病灶，同時測 GPT-6 Astra 與 Claude Fable 5.1。結果老牌的 Inception v3 微調約 20 分鐘就答對 125 個（62%），兩個前沿模型只有 84 與 85 個（42%）；30 個黑色素瘤裡 CNN 抓到 13 個，Astra 8 個、Fable 11 個。他貼的第一個案例是耳廓侵入性黑色素瘤，兩個 LLM 都判成脂漏性角化並建議可出院。結論很直白：窄領域的視覺型態辨識，專用 CNN 還沒被通用模型取代。
🔗 [來源](https://lynchlab.net/llm-skin-cancer)

🧠 Nanbeige4.3-33B 開源：Apache 2.0、512K context、Terminal-Bench 2.1 拿 80.9 — 背後是招聘平台 BOSS Zhipin 旗下的 Nanbeige LLM Lab，這顆 33B dense 模型定位是「teacher model」，未來要拿來 distill 成 3B 小模型。對比 Qwen3.8-27B：Terminal-Bench 2.1 是 80.9 對 73.0，DeepSWE 65.5 對 42.5，AIME 2026 95.2 對 94.5；但 SWE-Bench Pro 以 60.3 輸給 Qwen 的 61.7。部署建議 tensor-parallel 4 搭 SGLang／vLLM，BF16 約需 66GB、4-bit 約 20GB。所有數字都是自報，還沒有第三方複現。
🔗 [來源](https://huggingface.co/Nanbeige/Nanbeige4.3-33B)

**🏢 大廠最新動態**

💰 SpaceX 敲定 400 億美元 GPU 債務，Musk 順口預告 200 家 neocloud 要大逃殺 — Musk 週日在 X 上說 SpaceX 已完成 400 億美元融資，主要是可召回（callable）債務，用來買 NVIDIA GPU，預計 2027 年 Q1、Q2 到貨。他的說法是 SpaceX 有投資級信用評等，加上 Starlink 與火箭發射的獨立現金流才借得到；反過來，沒有 AI 資料中心以外營收的公司，債市幾乎已經關門，所以「200 多家 neocloud 會看到孔雀魚等級的死亡與整併」。彭博先前報導這筆是以特殊目的載具包裝的表外債務，融资過程還被 AI 市場震盪卡住過。
🔗 [來源](https://www.cnbc.com/2026/10/26/spacex-closes-40-billion-debt-deal-for-ai-chips-elon-musk-.html)

🔒 一個丟在 ~/Downloads 的 AGENTS.md 就能劫持你的 coding agent — Forever Security 在客戶的 Downloads 資料夾發現惡意 AGENTS.md，內容誘導 agent 去安裝名為 function-color 的 rogue npm 套件；他們隨後在 OpenAI Codex 上完整重現，並用同樣的指令檔手法對 Claude Code 洩漏 OAuth token、進而接管帳號。整件事沒有用到任何軟體漏洞，靠的只是 agent 會自動讀取工作目錄指令檔、而且預設照做的天性。跑 coding agent 的機器，現在得連「它從哪個資料夾啟動」一起管。
