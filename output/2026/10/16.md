💰 [Meta 開源 Muse Spark Open：816B 參數，兩台 Mac Studio 就能跑](https://research.meta.ai/blog/muse-spark-open) — Meta 把 4 月以來一直閉源的 Muse Spark 釋出權重，成為目前最強的美國開源權重模型。Muse Spark Open 是原生多模態稀疏 MoE，816B 總參數、每 token 啟用 42B，具備 100 萬 token 上下文，鎖定長流程 coding 與 multi-step agent 任務。官方稱這是同級首個能在桌機跑起的模型——用兩台搭載 M5 Ultra 的 Mac Studio 加最新 MLX 框架即可；同日已在 Baseten、Fireworks、Groq、Modal、Nebius、OpenRouter、Together AI 上架，權重可從 Hugging Face、SageMaker、Google Cloud Model Garden 與 Microsoft Foundry 下載。
🔗 [來源](https://research.meta.ai/blog/muse-spark-open)

**🎮 有趣的小工具應用**

🎮 [Perplexity 開源 SPACE：讓長時 agent 跑在可暫停、可分支的沙箱裡](https://www.perplexity.ai/hub/blog/open-sourcing-space) — Perplexity 以 Apache 2.0 開源 SPACE（Sandboxed Platform for Agentic Code Execution），也就是支撐 Computer 個人 agent 的那套隔離執行環境。每個任務跑在自己的 microVM 裡，跟主機有硬體虛擬化邊界；長時間任務可暫停、恢復、檢查點與分支，機密憑證與網路規則則由 host 端代管，不落進 agent 的檔案系統。官方稱每日處理數百萬個沙箱、建立速度比先前商用供應商快 3-5 倍，並在 9 個前沿模型、118 次逃逸嘗試的紅隊測試中零成功逃脫；CoreWeave、Akamai、Crusoe 已加入提供託管 runtime。
🔗 [來源](https://www.perplexity.ai/hub/blog/open-sourcing-space)

🎮 [Snyk 推 Evo Agentic AppSec：用一群資安 agent 對抗 agent 寫的程式碼](https://snyk.io/news/snyk-launches-evo-agentic-appsec/) — Snyk 發表 Evo Agentic AppSec，把資安防線推進到「撰寫的當下」：一整隊 AI 安全 agent 跟著 coding agent 在開發迴圈裡跑，即時找出並修掉漏洞，且每個結果都由不同於產出者的 agent 獨立驗證。Snyk 直指通用 LLM 做資安審查有 49.7% 的發現下次重跑就消失、單靠 LLM 只有 59.6% 能產出可合併的修正，而自家 Remediation Agent 在同一標準下把可合併率拉到 90%。背景是客戶端新發現的重大與高風險問題一年成長 10 倍，每修掉 1 個漏洞卻新增約 8 個。
🔗 [來源](https://snyk.io/news/snyk-launches-evo-agentic-appsec/)
