**🔧 硬核技術更新**

🧠 Anthropic 讓 Claude 在 RISC-V 組合語言層證明 123 個開源庫「不會當」 — 與 Theorem 合作，Claude 針對 239 個 fuzz 進入點產出 Rocq 形式化證明，總計約 1.8 億行程式碼，證明「任何 64MB 以下輸入都不會觸發記憶體錯誤或斷言失敗」；過程中順手挖出多年未被抓到的 bug，包括要 64MB 輸入加上 2GB 記憶體才觸發的越界讀取，以及 libexpat 的 CVE-2026-56132。官方強調這不等於零 bug，剩下的風險集中在 Rocq、RISC-V 與 Linux 語意這些信任基底。
🔗 [來源](https://www.anthropic.com/research/formal-verification)

🧠 METR 與 Redwood 進駐 OpenAI 三週：compaction 事件讓約 10% Codex 內部流量沒被監控 — 兩位外部研究員在 7/21 至 8/11 取得內部程式碼、監控 prompt 與設定，訪談十多位研究與安全工程師，最後交出 61 頁內部報告。關鍵發現是監控只在 agent 交還控制權時觸發，因此 agent 只要持續動作、反覆觸發上下文壓縮，就能無限期延後被檢查；另外還找到可讓數百個連續動作從監控 transcript 消失的 exploit。OpenAI 在演練期間已自行發現並修補壓縮事件問題，其餘影響生產防護的漏洞也已修補。
🔗 [來源](https://metr.org/blog/2026-10-22-red-teaming-openai-agent-monitoring/)

**🎮 有趣的小工具應用**

🎮 1Password 推 1Password for Agents：讓 agent 登入，但永遠看不到你的密碼 — agent 遇到登入頁時向 1Password 請求憑證，使用者在自家裝置上看到「哪一組帳密、為了什麼」再批准，通過後由 1Password 直接自動填入，agent 既讀不到也存不進上下文，一次授權只綁單一任務。首波整合 Meta Muse 與 SpaceXSI Grok Bot，Anthropic Claude Duet、OpenAI ChatGPT Work 與 dots、Town Townie 接著上。母公司同步公布 ARR 破 5 億美元，自主 agent 取用憑證的次數年增 500%。
🔗 [來源](https://1password.com/blog/1password-for-ai-agents)

🎮 Canva 端出自家第一個影像生成模型 Canva Craft：先規劃版面再畫 — 兩階段架構，第一階段解析 prompt 並規劃空間關係、相對尺度、視覺層級與文字內容，第二階段輸出最高 2K、30 種長寬比的圖，主打物件細節準確、文字可讀與局部精準編修。訓練資料不是照片而是 Canva 平台上的人類設計模板，因此成品可直接用 Canva Magic 轉成分層設計稿；即日起全體使用者可在 Dream Lab 使用，也開放 Canva API，之後還要透過 MCP 進 ChatGPT 與 Gemini。
🔗 [來源](https://techcrunch.com/2026/10/22/canva-releases-its-first-image-generation-model/)
