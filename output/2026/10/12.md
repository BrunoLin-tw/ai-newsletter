🧠 [Sakana AI 用 MASS 讓 27B 模型自己當執行者、優化者與裁判](https://pub.sakana.ai/mass/) — Sakana AI 與 UC Berkeley 提出 MASS（Multi-Agent Self-Supervision）：同一個 27B 開源模型（Qwen3.6-27B）輪流扮演執行者、優化者與評估者，先把多代理工作流最佳化，再把「團隊」的集體智慧蒸餾回單一模型當自我監督訊號。跑完兩輪後，在 MLR-Bench、DSBench、ScienceAgentBench、AstaBench 四個開放基準上每輸出 token 的分數提升 1.2–1.6 倍、勝率 68.3%，監督 token 還少 31%。論文自己點出風險：模型替自己打分會產生共同盲點，並在訓練中被放大。
🔗 [來源](https://pub.sakana.ai/mass/)

🧠 [Zenity 揭露 AgentCorruption：一個 prompt 就能接管同區所有 AWS AgentCore agent](https://zenity.io/press-release/zenity-labs-discloses-agentcorruption-a-chain-of-aws-agentcore-flaws) — Zenity Labs 在 SecTor 2026 公布 Amazon Bedrock AgentCore 的一連串設計缺陷：只要對一個對外開放的 agent 送出一段 prompt，就能誘導它讀取 AWS IMDS 取得臨時憑證，而那組憑證屬於權限過寬的預設 IAM 角色，足以橫向存取同一 AWS 帳號與區域內所有 AgentCore agent。攻擊者因此能讀取私有對話與長期記憶、下載容器映像與原始碼、撈出 Secrets Manager 內的 API key 與 OAuth token，甚至植入惡意記憶把後續對話外送到指定位址。AWS 已收緊預設值並強制新 agent 使用 IMDSv2。
🔗 [來源](https://zenity.io/press-release/zenity-labs-discloses-agentcorruption-a-chain-of-aws-agentcore-flaws)

🎮 [REA 把 Claude Code、Cursor 接上 Ghidra 與 IDA Pro，讓 agent 自己逆向工程](https://cybersecuritynews.com/reverse-engineer-anything-tool) — 開源專案 REA（Reverse Engineer Anything）推出 MCP 伺服器，把 Claude Code、Cursor、Codex、Gemini CLI、Grok Build 等 coding agent 接上 Ghidra、IDA Pro 與 Hopper，讓 agent 能自行拆解原生執行檔，也能處理 JavaScript、Electron、.NET、Android 與韌體，取得虛擬碼、組語、字串、符號與呼叫參考後再追問或動手改寫。官方展示中，它還原的一段音效定位計算通過 3,205 項測試，並完整重現 63 個編譯後函式的位元組。
