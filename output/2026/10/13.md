**🔧 硬核技術更新**

🧠 [Microsoft 端出 Maia 300：2027 年衝多吉瓦部署，每兆瓦多 40% token](https://blogs.microsoft.com/blog/2026/10/12/microsoft-to-expand-azure-maia-system-to-multi-gigawatt-deployments/) — 微軟宣布 Azure Maia 系列自 2027 年起擴到多吉瓦規模，讓 Maia 成為自家產品的推論主力。現行的 Maia 200 已進入量產、跑 Copilot 與 MAI 模型；Maia 300 針對長上下文推理、低延遲對話與多步 agent 任務設計，官方稱相較領先 GPU 系統每兆瓦可多出 40% token 輸出，96 加速器整櫃吞吐量達 Maia 200 的 7 倍。此舉核心是降低對 NVIDIA 的依賴並省下高昂推論成本。
🔗 [來源](https://blogs.microsoft.com/blog/2026/10/12/microsoft-to-expand-azure-maia-system-to-multi-gigawatt-deployments/)

🧠 [AMD 推 Helion 機櫃藍圖，開放規格直攻 agentic AI 基礎設施](https://ir.amd.com/news-events/press-releases/detail/1301/introducing-amd-helion-agentic-ai-compute-at-rack-scale) — AMD 在 OCP Global Summit 發表 AMD Helion agentic AI 機櫃，採用 OCP 開放式規格，讓客戶自由調配 CPU 核心密度、效能與功耗；可組純 CPU 機櫃（6th Gen EPYC，最高 32,768 核心，主打超大規模）或 EPYC + Instinct MI350P GPU 一體式機櫃（主打企業）。內建 token router 可在前沿與開源模型間分派 agent 呼叫，規格將捐給 OCP 社群。
🔗 [來源](https://ir.amd.com/news-events/press-releases/detail/1301/introducing-amd-helion-agentic-ai-compute-at-rack-scale)

🧠 [阿里 Qwen 開源 QwenGyre：讓小時級長流程 agent 訓練快 1.85 倍](https://www.marktechpost.com/2026/10/12/alibaba-qwen-introduces-qwengyre-elastic-reinforcement-learning-rl-for-xlong-horizon-agents/) — Qwen 團隊釋出 QwenGyre，一套針對「超長流程（xLong-horizon）」agent 的彈性強化學習框架，可在不打斷執行中的 rollout 下，於 rollout 與訓練間彈性重分配 GPU，解決多步 agent 訓練常見的 GPU 閒置。軌跡處理器會重建分支歷史、對部分進度給分、去重冗餘路徑。以 Qwen 3.8 2.4T 實測，48 步後把 NL2RepoBench 從 52.5% 拉到 58.5%。
🔗 [來源](https://www.marktechpost.com/2026/10/12/alibaba-qwen-introduces-qwengyre-elastic-reinforcement-learning-rl-for-xlong-horizon-agents/)

**🏢 大廠最新動態**

💰 [Meta 發表首款前沿模型 Muse Wonder，主打「active memory」](https://techcrunch.com/2026/10/12/meta-releases-its-first-frontier-model-muse-wonder/) — Meta Superintelligence Lab 發布 Muse Wonder 與 Muse Wonder Full，是公司首度挑戰前沿模型。兩者宣稱在基準上與 Fable 5.1、GPT-6 Astra 相當；Wonder 經 Meta Model API 開放，定價每百萬 input token 4 美元、output 20 美元，與 GPT-6 Sol、Opus 5.5 差不多，而更強的 Wonder Full 僅供 Muse Code 訂閱者、不走 API。Meta 特別強調「active memory」，稱其在 MemoryBench 上勝過 Fable、Opus 與 Astra。
🔗 [來源](https://techcrunch.com/2026/10/12/meta-releases-its-first-frontier-model-muse-wonder/)

💰 [IonQ 砸 13 億美元股票併購 Elisity，進軍量子時代零信任資安](https://www.cnbc.com/2026/10/12/ionq-elisity-acquisition-cybersecurity.html) — 量子運算公司 IonQ 同意以全股票交易收購零信任資安公司 Elisity，價值最高達 13 億美元（含最高 1.5 億美元績效獎勵金）。IonQ 想藉此把企業安全業務疊加到量子平台上，搶攻「量子時代」的後量子加密與身分安全市場，交易架構為先付一筆再加 earnout。
🔗 [來源](https://www.cnbc.com/2026/10/12/ionq-elisity-acquisition-cybersecurity.html)

💰 [IMF：AI 像「慢動作海嘯」，全球 40% 工作受影響](https://www.channelnewsasia.com/business/imf-says-ai-investment-keeps-global-growth-around-3-major-asia-benefits-6451936) — 在曼谷 IMF－世界銀行年會上，IMF 總裁 Georgieva 直指 AI 對勞動市場的衝擊是「慢動作的海嘯，但終究是海嘯」：全球約 40% 工作將被增強、降級或消滅，先進經濟體更高達 60%，低所得國家約 23%（反映的是採用落後而非免疫）。她同時指出 AI 基礎建設投資正把全球成長撐在約 3%，亞洲硬體供應鏈受惠明顯，但入門職缺被掏空、稅基遭侵蝕是長期隱憂。
🔗 [來源](https://www.channelnewsasia.com/business/imf-says-ai-investment-keeps-global-growth-around-3-major-asia-benefits-6451936)
