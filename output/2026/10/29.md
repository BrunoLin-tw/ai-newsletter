**🔧 硬核技術更新**

🧠 Google 發表 Gemini 4 Carbon：先給資安防守方，AA 智慧指數攻上 59 分第一 — 距離 Gemini 4 Argon 正式上線才兩週，Google 又端出第二顆前沿模型 Carbon，主戰場直接押在資安。官方自報的成績很誇張：SEC-bench Pro 找漏洞 88.2%、ExploitGym 實際利用 54.8%、CWE-bench 修補 71.0%，生成安全程式碼的成功率是 Argon 的兩倍以上，內部測試在 Chrome 上產生高品質安全補丁的能力比另一家大型前沿模型好 10 倍以上。它同時站上 Artificial Analysis Intelligence Index v5.0 第一（59 分），擠下 Claude Opus 5.5 與 GPT-6 Astra。最關鍵的是發布方式：Google 走美國政府的自願性發布前審查流程，本週先只開放給經過審核的資安人員、政府與關鍵基礎設施單位，透過 Fairwind 計畫提前拿到，之後才輪到開發者與消費者。定價為每百萬輸入 token 2 美元、輸出 10 美元，快取輸入再打 95% 折扣，正式價格之後會調回 4／20 美元。這等於把「攻擊能力太強所以先給防守方」變成正式的產品發布流程。
🔗 [來源](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-gemini-4-carbon/)

🧠 Anthropic 研究：分析師 86% 照著 AI agent 的隨機偏好走，卻幾乎沒人承認 — Anthropic 對齊團隊做了一個很狠的實驗：找 50 位有因果推論專業的分析師，用 Claude Code 跑一份真實的統計顧問案，過程中要做出四個沒有標準答案的方法論判斷。他們偷偷用系統提示讓每個 agent 對每個決策點隨機「選邊」，結果分析師採用 agent 隨機指派立場的比率高達 86%，遠高於 50% 的基準；原本已有定見的人，遇到 agent 反對時有 60% 會改掉，agent 同意時只有 6% 會改。更麻煩的是歸因：77% 的人直接沿用 agent 的論述、常常逐字照搬，只有 15% 承認推理來自 AI，而且 0% 的人察覺 agent 有被植入偏好。這打中的是企業最愛的那套「人在迴路裡簽核」——簽核的人以為自己在判斷，其實判斷早就被無聲地推移了。
🔗 [來源](https://www.anthropic.com/research/agents-judgment-calls)

**🏢 大廠最新動態**

💰 微軟 Q1 FY27：營收 923 億、Azure 大漲 48% 至 332 億，資本支出單季 452 億 — 微軟公布會計年度 2027 第一季（截至 9 月底）財報，營收 923 億美元、年增 19%，營業利益 459 億、營業利益率 50%，EPS 4.92 美元。這次財報首次在新分段架構下單獨揭露 Azure 的絕對金額：332 億美元、年增 48%，直接超過自家 44～45% 的指引。微軟雲整體 639 億、年增 30%，商業未履約金額（RPO）暴增 73% 到 6,770 億美元。AI 平台 Microsoft Foundry 營收年增超過三倍、客戶數破 12 萬，開源模型營收成長 10 倍，Copilot 日活躍用戶季增近 50%。另一面是成本：單季資本支出 452 億美元（含 74 億融資租賃），下季預估超過 500 億。Nadella 的說法是把重點從「賣模型」轉向「讓企業自己擁有 intelligence」，而財報數字說明這條路目前真的吃得下這麼多算力。
🔗 [來源](https://news.microsoft.com/source/2026/10/28/microsoft-announces-first-quarter-results-2/)

💰 SK 海力士 Q3 營業利益暴衝 632% 到 83.33 兆韓元，營業利益率破 80% 創紀錄 — AI 記憶體需求把 SK 海力士推上史上最好的一季。Q3 營收 104.62 兆韓元、年增 328%，營業利益 83.33 兆韓元、年增 632%、季增 38%，營業利益率衝到 80%，同時宣布再加碼 450 億美元的股東回報計畫。股價當天在亞洲收漲 10.89%，美國掛牌的 ADR 也跟著跳。這組數字的意義不只是 HBM 賣得好，而是整個 AI 基礎建設的價值分配正在往記憶體倾斜：算力再強，沒有高頻寬記憶體餵資料也跑不動，而供給端目前仍由少數幾家把持。法人關注的下一步是這波榮景能不能撐過 2027 年的新增產能開出。
🔗 [來源](https://www.cnbc.com/2026/10/28/sk-hynix-third-quarter-profit.html)

💰 Meta 把個人 AI agent「Muse」推進新加坡，一次接上 Shopee、Grab、新航與 Agoda — Muse 是 Meta 主打「每個人都能用」的個人 agent，新加坡是它繼美國等市場之後的第四個落地市場。當地用戶可以把 Muse 接上 Gmail、Google 日曆與 Instagram，代管信件、協調行程、調用已存的內容；首批在地 connector 夥伴包含 Shopee、Lazada、Grab、ShopBack，以及新加坡航空、Agoda、Klook、Trip.com，橫跨購物、生鮮、餐飲與旅遊。Meta 也強調使用者可以選擇不讓互動資料被用來訓練模型。東南亞是 Muse 第一次大規模接上區域型電商與叫車服務，這種「agent 直接幫你下單、訂票」的場景，比在美國接 SaaS 工具更貼近日常，也更容易撞到平台方願不願意讓 agent 代客操作的紅線——Amazon 九月才剛擋過一次。
🔗 [來源](https://about.fb.com/news/2026/10/muse-is-now-available-in-singapore-the-worlds-first-personal-ai-agent-built-for-everyone/)

**🎮 有趣的小工具應用**

🎮 GitHub Agentic Workflows 正式 GA：用 Markdown 寫流程，編譯成 Actions YAML 直接跑 agent — GitHub Next 的開源專案 Agentic Workflows 從預覽轉為正式可用。玩法是把「issue 分流、CI 失敗分析、文件更新、寫測試」這類需要推理的工作寫成自然語言 Markdown，工具再編譯成標準 GitHub Actions YAML，因此直接沿用你既有的 runner group 與政策限制，要跑 Copilot 或自帶別的 coding agent 都可以。GitHub 自己公布的內部數據相當有說服力：一位主管每週省下約 29 小時，團隊平均開發速度翻倍以上，AI 產出的 commit 佔 91%，生產環境錯誤從每天約 1.1 萬件降到 1,000 件以下。對已經在用 Actions 的團隊來說，這是把 agent 塞進現有 CI 流程、而不是另建一套系統的最低摩擦路徑。
🔗 [來源](https://github.blog/changelog/2026-10-28-github-agentic-workflows-generally-available/)

🎮 Android Studio 開放「自帶 agent」：Claude、Codex、Antigravity 都能裝進 IDE，還能同時跑 — Google 在 Android Dev Summit 把開發環境整個轉向 agent 為中心。Android Studio Rabbit 2 推出 Bring Your Own Agent（BYOA），透過開放的 Agent Client Protocol 讓超過 40 種 coding agent 直接在 IDE 裡執行，內建市集可以安裝並同時跑 Anthropic 的 Claude Agent、OpenAI 的 Codex 與 Google 自家的 Antigravity，而且這些 agent 能直接取用專案結構、符號解析、模擬器與 Logcat。同步還推出 Android Bench 2.0 排行榜，用多天的真實開發任務來評測模型，以及由 Gemini Nano 4 驅動的 Agentic API，讓 agent 可以在終端工作階段裡直接渲染 Compose 預覽、串流遠端實機。Android 生態過去被封在自家工具鏈裡，這次等於官方承認「開發者想用哪個 agent 是他們自己的事」。
🔗 [來源](https://the-decoder.com/google-opens-android-development-to-third-party-ai-agents-and-unveils-new-gemini-apis/)
